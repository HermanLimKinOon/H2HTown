# Separate 3D Farming Game Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a separate `/game-3d` tab that translates the existing 2D meadow, movement, farming, inventory, tree, and shop loops into a low-poly 3D world without changing the 2D game or its save.

**Architecture:** React Three Fiber renders an isolated world under `src/pages/game3d`. Pure TypeScript helpers own movement, collisions, farming, growth, inventory, economy, and save normalization; React components render that state and ordinary HTML dialogs provide accessible inventory and shop UI. The 3D world uses `h2h-game-3d-save-v1`, never the 2D save key or current Supabase row.

**Tech Stack:** React 19, TypeScript, Three.js, React Three Fiber, Drei, React Router, Tailwind CSS, Node test runner

**Spec:** `docs/superpowers/specs/2026-11-17-game-3d-design.md`

## Global Constraints

- Existing `src/pages/game/**`, `/game`, and `h2h-game-world-save` remain unchanged.
- New gameplay code lives under `src/pages/game3d/**` and the new route is `/game-3d`.
- The 3D save key is exactly `h2h-game-3d-save-v1`.
- The first version uses local persistence only and does not write to `game_saves`.
- Procedural meshes must be replaceable later by `.glb` assets without changing gameplay state interfaces.
- Desktop controls are WASD/arrows, `0–8`, left-click, right-click, and `I`; touch movement controls remain available on small screens.

## Review Focus

- Corrupt or old 3D local saves must normalize to safe defaults without reading or writing the 2D key; Task 1 pins this.
- Diagonal movement and large frame deltas must not pass through shops, trees, ponds, or world bounds; Task 1 pins this.
- Plants must advance only after watering each stage and cannot be harvested before stage 3; Task 2 pins this.
- Hotbar reassignment must not duplicate items and bag quantities must remain independent from slots; Task 2 pins this.
- Opening dialogs or typing in controls must stop movement and tool actions; Task 5 verifies this in the browser.
