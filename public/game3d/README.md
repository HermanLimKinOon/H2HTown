# H2H farmer asset

`farmer.glb` is an original procedural low-poly farmer model, generated by
`node scripts/create-farmer-asset.mjs`.

- GLB with embedded materials; no external texture dependencies.
- Y-up, +Z forward, boots at ground level; approximately 2.12 metres tall.
- Straw hat, cream shirt, denim overalls, brown boots and simple facial features.
- Named head, arm and leg pivot groups plus left/right tool sockets.
- Static model with transform pivots, not a skinned skeletal rig. No animation clips.
- Kept as a separate asset; the existing player has not been replaced.

Edit the generator to change shapes or colours, or open the GLB in a 3D editor.
