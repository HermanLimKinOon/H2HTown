# Local Blender reference likeness study

This is an independent mirror-only approximation authored locally in Blender.
No Meshy model or remote generation service was used. It is not an exact
reconstruction of the supplied illustration.

Starting topology, game skeleton and fitted clothing derive from the existing
MakeHuman Community CC0-based mirror-sculpted character. Original sources and
credits remain in mirror-sculpted.LICENSE.md, mirror-reference.LICENSE.md and
mirror-mpfb.LICENSE.md.

New Blender work: measured facial reshaping, adult jaw/neck proportions,
almond eyelid fitting, reference-guided vertex-colour skin painting, layered
hair/scalp and tapered brows, cream/grey/green sneakers with physical laces,
and a reference-derived replaceable shirt print. The supplied reference art
is user-provided, and no CC0 claim is made for that artwork or its derivatives.

Editable source: assets/characters/blender-reference.blend.
Reference and print: assets/characters/blender-reference/.
Builder: scripts/build-blender-reference.py.
Game export: public/game3d/blender-reference.glb.

All existing face/physique targets and the shared skeleton are retained. The
mirror stores drafts under h2h-blender-reference-preview-v1; this model is not
allowed to apply to the world. Existing world assets and selection are preserved.
