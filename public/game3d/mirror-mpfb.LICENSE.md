# MPFB mirror character — CC0 1.0

Generated with Blender 4.5.3 LTS and MPFB 2.0.18 from the official MakeHuman
base mesh, facial targets and system asset pack. All character assets used here
are CC0 1.0 Universal: https://creativecommons.org/publicdomain/zero/1.0/

Sources:
- https://github.com/makehumancommunity/mpfb2
- https://static.makehumancommunity.org/about/license.html
- https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html
- https://files.makehumancommunity.org/asset_packs/makehuman_system_assets/makehuman_system_assets_cc0.zip

Included system assets: young_caucasian_male skin; low-poly eyes; eyebrow001;
eyelashes01; teeth_base; short02, bob01, afro01 hair; male_casualsuit01 and
male_worksuit01 outfits; shoes01. Facial morphs use the bundled MPFB head,
chin, nose, eyes, mouth, cheek and eyebrow targets.

Core system asset copyright holders listed by MakeHuman: Data Collection AB,
Joel Palmius and Jonas Hauquier. The system pack explicitly releases these
assets under CC0. MPFB application code is separately GPL-3.0-or-later; it is
not shipped in the game. Blender is an authoring tool, not a game dependency.

Changes: male adult macro settings, fitted alternate assets, helper geometry
excluded, evaluated facial targets exported for every part, game-engine rig,
textures reduced to 1024px. Runtime mirror colours and morph weights are separate
from the playable farmer. The previous Daniel asset is retained unchanged.
