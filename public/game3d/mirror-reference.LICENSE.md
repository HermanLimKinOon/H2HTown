# Reference-inspired mirror character

Character base, facial targets, fitted hair caps, clothing and shoes: MakeHuman
Community core/system assets, CC0 1.0. See mirror-mpfb.LICENSE.md for sources and
the original system asset credits. Additional system assets used: eyebrow003,
short02 as the fitted swept-hair cap, male_casualsuit04 and shoes05 (all from the CC0 system pack).

The supplied character concept was used as a visual reference. This model is
an approximation built with Blender + MPFB, not a conversion of that image or
a model downloaded from Meshy. The world farmer is not changed.

Additional work: baked softer facial proportions, looser tee fit, projected shirt
artwork, sculpted tapered hair locks with fitted facial morphs, relaxed preview
arm pose. The original MPFB and Daniel models are retained separately.

Face/hair revision 2: wider, more open eyes, softer jaw and nose, fuller lips,
raised mouth corners, solid arched brows fitted to the face morphs, and layered
scalp-attached swept locks with separate shaded ridges. Warm skin shading and
the portrait camera are applied only in the mirror. Earlier test settings are
retained under h2h-mirror-reference-v1; this revision uses v2.

reference-mountain-shirt.png is newly AI-generated mountain/forest/sunset artwork
created for this project, stored separately so it can be replaced. It is not
claimed to be a MakeHuman CC0 asset. The sneaker mesh/texture is the unbranded
MakeHuman shoes05 asset; no brand affiliation is implied.

Editable source: assets/characters/mirror-reference.blend.
Rebuild using scripts/create-mirror-mpfb.py with --reference after its three paths.
